# C2: HISTSH's own history behind DCL's line editor

C2 builds on C1 (docs/C1.md) and keeps all of it: the pseudo-terminal, the prompt
markers, the hidden RECALL commands and the settle rule. DCL still edits the line
(D5). What changes is where up-arrow gets its history.

## History file

`SYS$LOGIN:HISTSH_HISTORY.LIS` (or `HISTSH$HISTORY`), one command per line, oldest
first, shared by all of a user's sessions.
- **Load** at start: the last `HISTSH$SIZE` lines (default 2000) into memory for
  up-arrow, and the newest that fit into DCL's own buffer (C1's snapshot and load), so
  the `RECALL` command still works.
- **Append** after every command: the entries DCL added since the last snapshot, by
  open-append-close with retries (N16). The newest entry is never appended twice in a row.
- **Trim** at start, when the file holds more than twice `HISTSH$SIZE` lines: rewrite
  the newest `HISTSH$SIZE` as a new version and delete the old one.

Other sessions' commands show up in a session at its next login, as in bash with
`histappend`.

## Finding new entries

After each command C1 already types a hidden `RECALL/OUTPUT`. With P the previous
snapshot and N the new one, the new entries are N after the longest overlap: the
smallest k for which P[k:] is a prefix of N gives N[len(P)-k:]. That holds whether the
oldest entries fell off (N13) or not, because DCL only ever appends (N14).

## Keys at a fresh prompt (IDLE)

| Key | Action |
| --- | --- |
| up-arrow, Ctrl/B | the previous entry: send Ctrl/E, Ctrl/U, then its text |
| down-arrow | the next entry; past the newest, an empty line |
| Ctrl/R | reverse incremental search (below) |
| anything else | to DCL, as in C1 |

Up-arrow and down-arrow arrive as `ESC [ A` / `ESC [ B`, or `ESC O A` / `ESC O B` in
application cursor mode. Any other escape sequence passes through whole. Moving through
history skips an entry equal to the one already on the line.

## Ctrl/R

HISTSH draws `(reverse-i-search)'text': match` over DCL's line itself.
- **Typing** extends the search text; Delete shortens it.
- **Ctrl/R again** finds the next older match.
- **Return** runs the match: Ctrl/E, Ctrl/U, the text, Return.
- **Escape, or an arrow key,** puts the match on the line to edit.
- **Ctrl/G or Ctrl/C** cancels and sends DCL Ctrl/R to repaint its own line.
